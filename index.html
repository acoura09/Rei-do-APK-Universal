Guia de Instalação

Pré-requisitos · Limpeza · Gerenciador

Limpeza — Para uma Nova Reinstalação
1
Desinstale o aplicativo completamente pelo Android, não apenas "limpar dados".
2
Apague os arquivos de configuração anteriores: .config .properties e a pasta Alarms/system_uf da raiz do armazenamento interno.
3
Também apague Android/.config dentro da pasta Android.
Deixar arquivos antigos pode causar conflito de IDs mesmo após reinstalação.
Google Backup — Restauração Automática
1
Acesse Configurações → Google → Backup e desative a opção "Restauração Automática de Apps".
2
Com essa opção ativa, ao reinstalar o app o Android pode restaurar automaticamente os dados antigos do backup — sobrescrevendo a nova configuração gerada.
Pode reativar após confirmar que os novos IDs estão funcionando corretamente.
Gerenciador de Arquivos — Arquivos Ocultos
1
No gerenciador de arquivos, ative "Mostrar arquivos ocultos" (arquivos iniciados com ponto . ficam ocultos por padrão no Android).
2
Extraia o ZIP gerado e copie os arquivos para os caminhos corretos:
/storage/emulated/0/.config
/storage/emulated/0/.properties
/storage/emulated/0/Android/.config
3
Confirme que os 3 arquivos estão visíveis no destino antes de abrir o app. Se não aparecerem, a opção de ocultos não está ativa.
Gerenciadores recomendados: MiXplorer, FX File Explorer, X-plore.
